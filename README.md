# ChargeNusa – Tugas SDG (deck HTML)

Buka `index.html` langsung di browser, atau deploy ke Railway:

1. Upload folder ini ke repo GitHub (atau `railway up` dari folder ini).
2. Railway otomatis menjalankan `npm install` lalu `npm start`.
3. Di Settings › Networking, klik "Generate Domain".

Navigasi: panah kiri/kanan atau spasi, klik/geser layar, F = layar penuh, link per slide: `#slide-5`.
